# OmniCompost Site — Changelog

All notable changes to the OmniCompost website and mockups. Dates are absolute.

## [1.3] — 2026-05-29

### Added
- **Per-product detail pages** — `product/<slug>.html` for all 9 SKUs, generated by
  `build.py` from `products.json` (Premium PDP: image, rating, price, description, spec
  list, add-to-cart, breadcrumb). Enriched `products.json` with `desc` + `details` per item.
- **Field Notes archive issues** — real article pages under `notes/`
  (`april-2026.html`, `march-2026.html`, `february-2026.html`); the newsletter archive
  "Read the opening" links now resolve.

### Changed
- Shop card titles (`index.html`, `shop.html`) now link to their product page.
- **Cart accessibility pass** — drawer is `role="dialog" aria-modal` with a focus-trap and
  Esc-to-close; cart button toggles `aria-expanded`; an `aria-live` region announces the
  cart count. Applied across `index.html`, `shop.html`, `newsletter.html`, product, and
  notes pages via the shared `cart.js`.

### Verified
- All `product/` and `notes/` routes 200; product PDP renders (image, 4 specs, price);
  9 card titles link to product pages; add-to-cart opens drawer + sets `aria-expanded`,
  Esc closes + restores focus, live region announces; no console errors (preview, port 8099).

## [1.2] — 2026-05-29

### Added
- **`products.json`** — single source of truth for the catalog (9 SKUs: store metadata +
  per-product id, slug, name, category, price, featured, badge, cta, image, alt, rating, blurb).
- **`build.py`** — regenerates the product grid (the `BUILD:SHOP` marker region) in
  `index.html` and `shop.html` in place from `products.json`, emitting the existing Premium
  `.pcard` markup so the design is unchanged. Re-run with `C:\anaconda\python.exe build.py`.

### Changed
- `index.html` and `shop.html` product grids are now generated, not hand-edited — wrapped in
  `<!-- BUILD:SHOP -->` … `<!-- /BUILD:SHOP -->` markers.

### Verified
- `build.py` rebuilds both pages (9 products each); 9 `.pcard`s render, digester stays featured
  2×2, filters work (garden → 3), add-to-cart adds, cart count persists index → shop, no console
  errors (preview, port 8099).

## [1.1] — 2026-05-29

### Added
- **Cart persistence** — cart now saved to `localStorage` (`oc_cart`) and synced across
  pages and browser tabs (`storage` event).
- Shared **`cart.js`** — single source of truth for add-to-cart, drawer, qty, filters,
  and persistence. `index.html` refactored to use it (inline cart removed).
- **`shop.html`** — dedicated full-catalog page (9 SKUs, filters, cart drawer).
- **`newsletter.html`** — Field Notes sign-up page with archive teaser and client-side
  form confirmation.

### Changed
- Header + footer nav now link to `shop.html` and `newsletter.html`.

### Verified
- Cart count + contents persist across index → shop → newsletter; filters and the
  newsletter form work; no console errors (preview, port 8099).

### Roadmap
- Added Track A (commerce build): Snipcart checkout, per-product pages, `products.json`
  single-source, ESP for newsletter, inventory, delivery gate, accessibility pass.

## [1.0] — 2026-05-29

### Added
- Full production main site ([index.html](index.html)): Premium landing shell + storefront
  in one page — 9 products (digester featured 2×2), filter chips, working slide-in cart
  (live count, subtotal, qty +/−, remove, duplicate-merge).
- Multi-SKU shop + working cart added to every mockup: premium-a (Editorial),
  premium-b (Gallery), family (Mainstream Family). premium-c (Boutique) already had one.
- Kids mockup ([mockups/kids/index.html](mockups/kids/index.html)) — Worm Crew, engagement-only (no cart by design).
- Mockups picker page ([mockups/index.html](mockups/index.html)).
- [REVIEW.md](REVIEW.md) — overall review of the main website (9.6/10).
- [mockups/RATINGS.md](mockups/RATINGS.md) — ratings for all mockups + main site.

### Changed

  main site, premium-a/b/c, and the picker. Family and Kids keep their own marks by design.
- Reworked all mockups + main page around a 7–10 SKU consumables store while keeping the
  digester featured.
- Renumbered main-site Roman-numeral sections to fit the new Shop section (II).
- Main-site digester CTA changed from a Reserve `mailto:` to a working Add-to-cart.
- RATINGS.md rewritten for the finished state (was a first pass that flagged missing shops).

### Fixed
- Kids/Family: swapped 🪱 (renders blank on Windows 10) → 🐛.
- Kids hero sticker given a white card backing for the sticker-book aesthetic.

### Verified
- Main site, premium-a, premium-b, family carts all add correctly; no console errors;
  no broken images; responsive shop grid confirmed (preview, port 8099).

### Known stubs (backend, not design)
- Checkout is a demo alert; no per-product pages; no live inventory; cart is session-only;
