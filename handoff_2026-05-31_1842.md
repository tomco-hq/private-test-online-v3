## Decisions & reasoning

- **Reorder over leave-as-is (Flag A):** the Featured block explains the worms/method
  and is a companion to §III; sitting after the gallery it read as a late repeat.
  Moving it tightens the arc method → trust → payoff. Unnumbered block, so no
  Roman-numeral churn and no nav-anchor changes.
- **Shop stays at §II (Flag B, NOT changed):** showing the full catalog before the
  trust-building is a valid commerce-early pattern, and §I already sells the hero
  object. Flagged as a possible A/B *only if* conversion data later shows drop-off —
  reordering it WOULD shift Roman numerals + `#shop`/`#how` anchors, so it's a
  deliberate change, not a quick edit. Left for the user's call.
- **Footer = fixed public `v0.9`:** user's explicit instruction — the v1.x versioning
  is internal-use (changelog/roadmap) and should not be visible to the public.
- **Mainstream→Premium batch tone-filter REJECTED (tested twice).** A filter
  (desaturate ~0.72, brightness ~0.92, contrast ~1.05, warm WB R×1.04/B×0.94) only
  fixes *colour* offenders. It cannot fix faces, flash highlights, off-brand vessels,
  or busy/no-negative-space composition — the things that actually disqualify
  mainstream shots. Confirmed specifically on the two `premium_photo-*` scrap files
  (scrap-bin-person + scrap-rainbow flatlay): both also turned out to be **watermarked
  comps**, doubly unusable. No filtered copies were made. This finding is now baked
  into the skill so it isn't re-attempted.
- **Watermarked-but-good images get parked, not dismissed:** hence `_hold-licensed/`.
  Keeps real candidates visible while making the licensing gate unmissable.

## Conventions & preferences (standing, user-held)

- **Premium voice only on this site:** noun-first titles, Roman numerals, exact
  numbers, **zero exclamation points**, cream `#F4EDE0` + sage/terracotta/ochre/teal,
  Fraunces + Inter, sharp corners. American English. (See `omnicompost-design-system`
  skill — authoritative.)
- **Premium image register:** Kodak-Portra warm-muted, soft diffused / north-window
  light, matte not glossy, partial hands NO faces, negative space, shallow DOF,
  heirloom/textural subjects. (See `omnicompost-image-sourcing` skill +
  `image_register_index.md`.)
- Show a visible numeric rating on product/comparison deliverables by default.
- Living docs carry a `_Last updated: YYYY-MM-DD_` stamp — update on every edit.
- Prefer skills over CLAUDE.md for repeated workflows; progressive disclosure keeps
  token cost low. The user actively asks for workflows to be skill-ified.
- Use isolated subagents for large image batches so image tokens stay out of the main
  thread; only verdict tables return.

- **Git:** the user moves everything to a private git themselves — do NOT init,
  commit, or push. DO flag new binary assets so they include them. (This session
  added 3: `assets/img/garlic-cloves-slate.jpg`, `eggshell-pail.jpg`,
  `walnut-shells-slats.jpg`. The `_hold-licensed/` files are parked comps, NOT for
  the live repo.)
- **Licensing:** never ship a watermarked comp. `premium_photo-*` / `premium_vector-*`
  are Unsplash+ (subscription) — confirm the seat before using any of them. Plain
  `*-unsplash.jpg` are standard Unsplash License (commercial OK, no attribution).
- **No secrets in repo** (`ESP_ENDPOINT` is a form URL; Snipcart public key is
  publishable).
- **Don't hand-edit** `product/*.html` or the `BUILD:SHOP` regions — `build.py` owns
  them. Edit `products.json` or the `build.py` template, then rebuild.
- **Python/pip via PowerShell + `C:\anaconda\python.exe` only** — never Git Bash (it
  mangles the path + leading slashes). AVIF needs `import pillow_avif` before PIL open.
- Don't mix another tier's voice/palette into Premium.
