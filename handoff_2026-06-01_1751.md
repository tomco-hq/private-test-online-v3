## Decisions & reasoning
- **QR embedded as data-URI, not a linked file:** the guides render in different folders via
  a temp-copy pipeline; a data-URI is path-independent and keeps each guide self-contained.
- **302 not 301 for redirects:** 301s are cached hard by browsers/scanner apps; 302 lets the
  PDF target be repointed freely. Promote to 301 only when a destination is truly final.
- **Family cart sidesteps the OC gate via markup, not a code fork:** plan §7 forbids forking
  cart.js logic. Making checkout an `<a>` and the footer `.dfoot` skips both OC-specific
  features through cart.js's own existing conditionals — zero logic change.
- **v3a over v2:** structural, not cosmetic — safety hierarchy + system tokens + the
  self-updating QR/PDF loop.
