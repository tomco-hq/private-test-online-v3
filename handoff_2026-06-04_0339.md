## 3. Decisions and the reasoning behind them

- **Profile v5's central finding:** Across five invented founders with unrelated
  biographies, the *values, exact specs, and creed were identical*. That invariance is the
  real author projecting, not the characters — non-circular evidence (one honest changelog
  could be QA; five personas preaching the same sermon is the author's default). One-line:
  *"the honesty isn't a register they deploy but the temperament they can't switch off."*
- **v4 hero contrast was a real failure, not a theoretical one.** A pixel-accurate canvas
  proof (image drawn with real `object-fit:cover` + filter + scrim composited, lightest
  pixel under the headline sampled) gave worst-case **2.74** contrast — below AA-large.
  Fixed by deepening the scrim (`…,.12 34%,.58 64%,.9 100%`); re-proof = **4.1**, passes
  AA-large. v5/v7 avoid the gamble entirely via a **solid ink-on-paper plate** behind the
  headline (AA by construction). This is the preferred pattern going forward.
- **v6–v8 each dramatize one v5 finding:** v6 = the invariance ("same promise, whoever
  makes it"); v7 = under-promise/limits (the limits ledger, each limit tied to a measured
  number); v8 = "range in register, not character" (same creed in a B2B register).
- **v8 is judged as a register demo, not a Premium candidate** — it deliberately uses the
  B2B system (navy `#1F3A4D`/teal `#2C7A78`, IBM Plex Mono, data table). Scored 9.0 as a
  demonstration; it would fail as a Premium page.
- **v6's named portrait slightly undercuts its own thesis** (the promise matters *more than*
  who makes it, then it adds a face). Copy holds both ("the name may change; the four lines
  will not") but it may be stronger face-less. Flagged, user's call.
- **The user-supplied refined fork (v4b) carried editor artifacts** — an embedded
  `<script src="https://claude.ai/…">` and an `<image-slot>` custom element needing a
  missing `image-slot.js`. Both were stripped for v4b/v5/v6/v7/v8: remote script removed,
  product image is a plain labelled placeholder div, CTAs point to `../shop.html`.

## 4. Conventions and preferences (user, observed this session)

- **Keep versions, never overwrite** — each iteration is a new file (v1, v2, … v4b, v5).
- **Numeric rating on every review/comparison deliverable**, one decimal, justified by
  subtraction (house rule; enforced by the `design-review` skill).
- **Honesty as the product ethos** — under-promise, exact measured numbers (5 gal/day,
  50–90% water, 2 weeks unattended, household of 4, 14 prototypes), no hype, zero
  exclamation points in Premium voice.
- **Distinct founder per variant** — the user explicitly wanted different people, not one
  face reused (that drove v2/v3 personas and now v6/v7/v8 names).
- The user iterates in **discrete directives** — do the asked task, then stop and report;
  don't run ahead on unprompted open items.

## 5. Constraints / don't-do

- **No new synthetic face may go live as a real named founder** without real photography or
  an illustration label. This is the standing pre-launch gate.
- **Local images only** — never hotlink; host under `about-pages/img/` or site `assets/img/`.
- **No external scripts / no Node deps** in shipped pages (why v4b's artifacts were stripped).
- **Premium voice rules** (cream `#F4EDE0`, Fraunces+Inter, sage/terracotta/ochre/teal,
  sharp corners, Roman numerals, exact numbers, zero exclamation points). Don't mix tiers
  except v8, which is an intentional B2B-register demo.
- **Run Python via PowerShell**, never Git Bash (it mangles `C:\anaconda\python.exe`).
- Don't hand-edit `product/*.html` or `BUILD:SHOP` regions — `build.py` owns them.
