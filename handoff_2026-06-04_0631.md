## 3. Decisions and the reasoning behind them

- **Stay the course on demographics; branch only at the tier line.** The cast's shared
  temperament (restrained solo maker) is a brand asset ("same promise whoever makes it"), so
  the two **real** demographic gaps — no Asian-American founder, compressed age range — were
  closed by **changing face/background, not temperament** (v9/v10). The unserved *audiences*
  (Gen-Z/values-loud, fixed-income, business buyers) are voice/tier gaps, not founder gaps —
  they belong to Family/Kids/B2B, not a new Premium founder. (Full argument in the dossier.)
- **Real photos over monogram.** User rejected the initials-tile placeholder; sourced real
  Unsplash portraits (commercial-OK license, no attribution required). Vetted via contact
  sheets: picked a warm, matte, authentic woman (founder-9) and a dignified older working man
  (founder-10), rejecting glamour, dramatic, and unhoused-looking candidates for register fit.
- **Founder image near the top on every page**, per explicit user instruction "like v5".
  Implemented as a flex `.intro` row rather than a float, because v6's section I is a CSS grid
  (`.creed`) and a float would overlap grid items.
- **Two-doc-format cleanup:** the markdown drafts and the superset docx were redundant;
  consolidated to one docx and archived the rest, per the project's single-source-of-truth ethos.

## 4. Conventions and preferences (user, observed)

- **Keep versions, never overwrite** — each iteration is a new file (v9, v10; profile v6).
- **Numeric rating on every review/comparison deliverable**, one decimal, justified by
  subtraction (enforced by the `design-review` skill).
- **Premium voice** — cream `#F4EDE0`, Fraunces+Inter, sage/terracotta/ochre/teal, sharp
  corners, Roman numerals, exact numbers, **zero exclamation points**. v8 is the only B2B-
  register exception (navy/teal, IBM Plex Mono, data table) — an intentional demo.
- **Distinct founder per variant** — the user wants different people, not one face reused.
- **Run Python via PowerShell**, never Git Bash. `C:\anaconda\python.exe`.
- **User iterates in discrete directives** — do the asked task, then stop and report.
- Docx builders are one-shot Python scripts in `notes/`, `os.path`-relative, re-runnable.

## 5. Constraints / don't-do

- **Founder-photo gate (standing pre-launch gate).** No face may front a live *named* founder
  without real photography or an illustration label. Two flavors now:
  - v1–v8: synthetic AI faces.
  - **v9/v10: real, identifiable Unsplash people standing in for fictional founders** — a
    *sharper* version of the gate (consent / misrepresentation, not licensing). The Unsplash
    license itself is commercial-clear. Replace with the actual founder's photo or relabel
    before launch.
- **Do not reintroduce the monogram/initials placeholder** — user rejected it.
- **Local images only** — host under `about-pages/img/`, never hotlink.
- **No external scripts / no Node deps** in shipped pages.
- Don't hand-edit `product/*.html` or `BUILD:SHOP` regions — `build.py` owns them.
